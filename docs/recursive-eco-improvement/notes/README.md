# Per-paper notes

One file per source, named for its identifier so it matches its `SOURCES.md` row without
a lookup: `2510.24797--berg-2025.md`.

**The PDFs do not live here.** They live in the private Google Drive folder
`recursive-eco-research-corpus` (id `1mfHuDAHdl7ABodqN_nJbjfQl4siGkaar`), because this
repo is public and most of them are not redistributable. See `../00-AGENDA.md`.

Template — keep it short, four headings, paraphrase only:

```markdown
# <Author year> — <Title>

`SOURCES.md` row: <identifier> · read-status: FULL | ABSTRACT | SUMMARY · read on <date>

## Claim
What the paper actually argues, in its narrowest defensible form — not the form that
would be most useful to us.

## Method
How they got there, and the one methodological choice a hostile reviewer would attack first.

## What would make it wrong
The observation that would falsify it. If none exists, say so — that is a finding about
the paper, not a gap in these notes.

## Consequence here
Which property in `01-Q2-convergent-properties.md` this strengthens, weakens or leaves
untouched, and whether any prose in this programme now needs changing.
```

Quotation: under ~30 words, attributed, and only where the exact wording carries the
argument. Everything else is paraphrase.
